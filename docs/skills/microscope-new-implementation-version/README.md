# microscope-new-implementation-version

This skill provides instructions for creating a new Implementation Version of an existing Microscope implementation.

## Features

- **Cloning**: Automatically clones the implementation class, test class, and metadata.
- **Versioning**: Increments the Implementation Version number based on the highest existing version.
- **Renaming**: Handles all renaming of classes and internal references to ensure the new version is self-contained.
- **Consistency**: Ensures the new version is identical in logic to the source version unless modifications are requested.

## Usage

To run this skill in your AI Code Generator terminal simply ask the tool to "run the Instructions for the AI Code Generator in the file skills/microscope-new-implementation-version/SKILL.md to create a new implementation version of an existing Microscope *Method Iteration*.". 

## Testing

The easiest way to test this skill is to use the existing Payment service and method created by the microscope-new-method-setup skill.
