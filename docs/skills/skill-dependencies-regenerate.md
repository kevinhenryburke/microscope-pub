# Regenerating the Skill Dependencies Diagram

As your collection of skills grows, you can easily regenerate the diagram in `skill-dependencies.md` to keep it up to date.

The diagram is generated by scanning the references inside each `SKILL.md` file located in the `/skills` directory to see which other skills or shared resources they rely on. 

## Instructions for Regeneration

The easiest way to regenerate the diagram is to ask Antigravity (or your AI assistant) to do it for you using the following prompt:

> **"Please regenerate the mermaid diagram in `skills/skill-dependencies.md` by scanning the `SKILL.md` files in the `/skills` folder. Map out the references between the different skills as well as any shared resources they link to (like `CommonGrounding.md` and `SelfValidationChecklist.md`). Please simplify the final graph by removing any transitive/commutative dependencies (e.g. if Skill A references Skill B and Skill B references a shared resource, please omit the direct link from A to the shared resource to keep the graph clean). Keep the output as a simple `mermaid` block in the existing `skill-dependencies.md` file."**

### Manual Process (If doing it by hand)

If you need to update it manually, follow these steps:

1. **Scan `SKILL.md` files:** Go through each subfolder inside `/skills` and read its `SKILL.md`.
2. **Find references:** Look for markdown links or direct mentions of `shared/` files (e.g. `[CommonGrounding.md](../shared/CommonGrounding.md)`) or other skills (e.g. `microscope-new-implementation-version`).
3. **Map the Edges:** Create a Mermaid `graph TD` adding a node for every newly discovered skill and drawing a directional edge (`-->`) from the referring skill to the target skill/file. 
4. **Clean up Transitive Edges:** To prevent a messy "spiderweb" graph, remove redundant paths. If `Skill A --> Skill B` and `Skill B --> Resource C`, then remove the direct link `Skill A --> Resource C` because it is already logically implied.
5. **Update the Diagram:** Replace the mermaid block inside `skills/skill-dependencies.md` with your new structural mapping.
